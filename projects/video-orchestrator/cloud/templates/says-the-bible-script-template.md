# Says the Bible Script Template

## Channel Profile
- **Duration:** 60 seconds
- **Format:** Narrative, Scripture-driven
- **Tone:** Reverent, scholarly but accessible
- **Key Requirement:** Theological review REQUIRED (blocks automation)
- **Privacy:** All scripts private until explicitly published

---

## Structure (Timings)

### Hook (0–5s)
Establish the theological question or common misconception.

**Pattern:**
```
Many Christians ask: [TOPIC_TITLE]

[Pause]

The answer matters. Let's look at what Scripture says.
```

**Guidelines:**
- Direct, reverent tone
- Assume Christian audience
- Frame as answerable from Scripture

### Body (5–50s)
Theological explanation with Scripture support.

**Pattern:**
```
Scripture reveals [MAIN_THEOLOGICAL_CLAIM]:

- [SCRIPTURE_REFERENCE]: [RELEVANT_PASSAGE_or_PARAPHRASE]
- [SCRIPTURE_REFERENCE]: [REINFORCING_PASSAGE]

This matters because [THEOLOGICAL_IMPLICATION].

[OPTIONAL_COUNTERARGUMENT]: Some claim [OBJECTION]. But Scripture is clear: [REFUTATION].
```

**Requirements:**
- Minimum 1 direct Scripture quote or reference
- Explain theological significance
- Address common objections (if applicable)
- Use accessible language for non-scholars
- Maintain scholarly accuracy

### Application (50–55s)
Practical implication for Christian life.

**Pattern:**
```
This changes how we [PRACTICAL_APPLICATION].
```

**Guidelines:**
- Connect theology to lived faith
- Be specific and actionable
- Maintain reverent tone

### Call to Action (55–60s)
Channel subscription/engagement.

**Pattern:**
```
If this has been helpful, subscribe to explore more Scripture-based answers to questions Christians face.
```

**Tone:** Warm, inviting, reverent

---

## Word Count & Formatting

- **Target:** 150–200 words
- **Script format:** Plain Markdown
- **Scripture references:** Include book, chapter, verse (e.g., "John 3:16")
- **Paraphrases:** Mark clearly as "paraphrase" to distinguish from direct quotes

---

## Approval Gate

**Before publishing, script MUST:**

- [ ] Theological accuracy verified
- [ ] Scripture citations checked
- [ ] Tone is reverent (not sensational)
- [ ] No heretical claims
- [ ] Accessible to target audience
- [ ] No unnecessary jargon
- [ ] Clarity of main claim

**Theological Review:** REQUIRED  
**Reviewer:** Qualified theologian or Bible scholar  
**Blocking:** ✓ YES — automation paused until approved

## Examples

### Example 1: Does Baptism Save?

```markdown
# Does Baptism Save?

## Hook
Many Christians ask: Does baptism save?

The answer matters. Let's look at what Scripture says.

## Body
Scripture reveals a nuanced answer: baptism is vital, but faith is the foundation.

Peter writes in 1 Peter 3:21 that baptism saves—but the context is crucial. 
Mark 16:16 also connects baptism to salvation, yet Jesus affirms the thief on the cross without baptism.

This matters because we must avoid two errors:
- Thinking baptism is optional (it's not—it's Christ's command)
- Thinking baptism alone saves (faith in Christ is the root)

## Application
This changes how we view baptism: not as mere ritual, but as public declaration of faith and obedience to Christ.

## Call to Action
If this has been helpful, subscribe to explore more Scripture-based answers to questions Christians face.
```

## Theology Safety Guardrails

These are red flags during review. Do not approve if:

1. **Heretical claims** — Scripture misused to support non-biblical doctrine
2. **False balance** — Presenting false doctrines as equally valid (e.g., "Some say Jesus wasn't God")
3. **Sensationalism** — "You won't BELIEVE what Scripture says about..."
4. **Vagueness** — Theological claim without Scripture support
5. **Contradiction** — Claims one thing, then contradicts it later
6. **Decontextualization** — Quoting verses outside their original meaning
