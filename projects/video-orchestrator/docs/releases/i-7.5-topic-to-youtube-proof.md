### Current State: BLOCKED (By Design)

**Blocker:** ProChat YouTube OAuth token not configured

**AWS Secrets Manager Status:**
```
✅ Says the Bible:  prochat/youtube/says-the-bible/oauth-token (configured)
⏳ ProChat:         prochat/youtube/prochat/oauth-token (PENDING)
```

**Why Not Deployed:**
1. ProChat YouTube channel has not been authenticated with OAuth
2. AWS Secrets Manager does not have valid ProChat credentials
3. Publishing Lambda checks for secret before attempting upload
4. Returns error: "Secret not found: prochat/youtube/prochat/oauth-token"

### What Would Happen If ProChat OAuth Were Configured

1. Publishing Lambda would read secret from Secrets Manager
2. Validate token is valid (not expired)
3. Check `privacyStatus: "private"` (enforced by channel config)
4. Upload video to ProChat YouTube channel as **private**
5. Update `publish.json` with:
   - `publishStatus: "uploaded"`
   - `platforms.youtube.status: "uploaded"`
   - `videoId: <YouTube video ID>`
   - `url: https://youtu.be/<videoId>`

