## Overview

I-7.2 implements the Topic Intelligence layer: a deterministic ranking system that surfaces the most valuable content candidates for each YouTube channel. Topics are scored, ranked, and exposed through Brain Core API endpoints for consumption by Brain Console and downstream systems.

                            ↓

### Decoupling: Mind ↔ Brain ↔ AWS

- **Mind** knows about: Obsidian, Brain Console plugin, user workflows
- **Brain Core** knows about: API, provider layer, file reading, normalization
- **AWS** knows about: actual video pipelines, state machines, Lambda functions
- **Connection:** Mind calls Brain Core API, never touches AWS directly

This prevents:
- Credentials leaking into Mind vault
- Direct AWS dependencies in Obsidian
- Configuration drift between storage and runtime

## Schema

### Topic Backlog JSON

```json
{
  "channelId": "says-the-bible",
  "topicBacklog": [
    {
      "topicId": "stb-baptism-001",
      "title": "Does Baptism Save?",
      "score": 92,
      "status": "candidate",
      "reasoning": [
        "High theological relevance",
        "Common misconception in evangelical circles",
        "Directly addresses Reformation vs. Catholic tension"
      ],
      "createdAt": "2026-05-31T21:00:00Z"
    },
    {
      "topicId": "stb-repentance-002",
      "title": "What is Biblical Repentance?",
      "score": 88,
      "status": "candidate",
      "reasoning": [
        "Foundational to gospel",
        "Often confused with remorse",
        "Bridge to discipleship content"
      ],
      "createdAt": "2026-05-31T21:00:00Z"
    }
  ]
}
```

**Fields:**
- `topicId` — Unique identifier (format: `{channel}-{topic}-{index}`)
- `title` — Human-readable topic title
- `score` — Relevance/priority (0-100)
- `status` — Enum: `candidate`, `in-progress`, `published`, `archived`
- `reasoning` — Array of strings explaining why this topic ranks here
- `createdAt` — ISO 8601 timestamp

### Brain Core Provider Response

```typescript
interface TopicCandidate {
  topicId: string;
  title: string;
  score: number;
  status: "candidate" | "in-progress" | "published" | "archived";
  reasoning: string[];
}

interface ChannelStatus {
  channelId: string;
  displayName: string;
  youtubeEnabled: boolean;
  publishingStatus: "ready" | "blocked" | "paused";
  topCandidates: TopicCandidate[]; // Ranked, top 5
  totalTopics: number;
}

interface VideoOrchestratorStatus {
  channels: ChannelStatus[];
  pipelineReady: boolean;
  lastUpdated: string;
}
```

---

## Ranking Algorithm

Topics are ranked deterministically:

1. **Primary sort:** Status priority
   - `candidate` (0)
   - `in-progress` (1)
   - `published` (2)
   - `archived` (3)

2. **Secondary sort:** Score (descending, high to low)

3. **Limit:** Top 5 per channel

**Example:** Says the Bible topics sorted:

| Rank | Status | Score | Title |
|------|--------|-------|-------|
| 1 | candidate | 92 | Does Baptism Save? |
| 2 | candidate | 88 | What is Biblical Repentance? |
| 3 | candidate | 85 | Faith vs. Works |
| 4 | candidate | 82 | OSAS: Once Saved, Always Saved? |
| 5 | candidate | 95 | Atonement Theories |

Note: Atonement (95) ranks 5th, not 1st, because sorting is:
1. All candidates (status=0) sorted by score
2. All in-progress (status=1) sorted by score
3. And so on...
