# I-8.3c Release: AWS Video Operational Job API (Phase A)

**Status:** Phase A Complete (Brain Core API layer)  
**Phase B:** Brain Console UI redesign (in progress separately)  
**Phase C:** Full proof & integration tests (planned)

---

## Scope

Phase A adds 4 new **read-only** operational endpoints to Brain Core that expose video job state in a normalized format. These endpoints are the data layer for the AWS Video operational console in Brain Console (Phase B).

**Important:** Phase A is **read-only API only**. No publish operations. No YouTube interaction. No Brain Console UI changes in this phase.

---

### 2. GET `/api/video-orchestrator/jobs/{jobId}`

Returns the full normalized job summary for a single job.

**Path Parameters:**
- `{jobId}`: Job ID (e.g., `prochat-real-001`)

**Response:** Same schema as recent jobs (single job object wrapped in `data`)

**HTTP:** 200 OK, 404 if job not found, 500 error

## Implementation: Status Normalization

The normalized job status is a union type:

```
'draft' | 'awaiting_approval' | 'approved' | 'generating' | 
'generated' | 'ready_to_publish' | 'publishing' | 'published' | 'failed'
```

### Normalization Logic

Status is determined by examining metadata files in order of terminal state precedence:

1. **publish.json** `publishStatus = "uploaded"` → `published`
2. **publish.json** `publishStatus = "publishing"` → `publishing`
3. **status.json** `status = "complete"` AND `completedSteps` includes `thumbnail_generated` → `ready_to_publish`
4. **status.json** `status = "generating"` → `generating`
5. **script.json** `approval.status = "approved"` (no generation in progress) → `approved`
6. **status.json** `status = "complete"` (after generation) → `generated`
7. **script.json** `approval.status = "pending"` → `awaiting_approval`
8. **status.json** `failedStep` exists → `failed`
9. Default → `draft`

### Progress Mapping

Progress percentage (0–100) is calculated from status:

| Status | Progress |
|--------|----------|
| draft | 0 |
| awaiting_approval | 20 |
| approved | 30 |
| generating | 50 |
| generated | 70 |
| ready_to_publish | 80 |
| publishing | 90 |
| published | 100 |
| failed | 0 |
