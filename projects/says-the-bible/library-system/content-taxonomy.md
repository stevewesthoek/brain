📄 CONTENT TAXONOMY

Version: v0.1
Date: 2026-02-27
Purpose: Routine navigation → library scalability → future SaaS bundles
Confidence: High (0.92)

⸻

Core Principle

Every audio must be classifiable across multiple axes simultaneously.

Single categories kill discoverability.
Multi-axis taxonomy enables:

• playlists
• recommendations
• bundles
• subscriptions
• AI suggestions later

Think in dimensions, not folders.

⸻

1️⃣ Narrative Axis (Story Type)

This is the cognitive entry point.

Values:

• ORIGIN — creation, beginnings
• JOURNEY — movement, calling
• TRIAL — danger, adversity
• RESCUE — protection, salvation
• WONDER — mystery, imagination
• TEACHING — meaning, wisdom

Examples:

Creation → ORIGIN
Noah → RESCUE
Joseph → TRIAL
Jonah → WONDER
Matthew Light → TEACHING

Why this matters:
Narrative type predicts emotional need.

⸻

2️⃣ Emotional Axis (Bedtime Function)

This is the real product layer.

Values:

• CALM
• SAFETY
• TRUST
• HOPE
• COMFORT
• AWE

Every audio must have one primary emotional tag.

Example:

Psalms Rest → CALM
Shepherd → SAFETY
Noah → TRUST
Joseph → HOPE
Jonah → AWE

This axis drives playlists.

⸻

3️⃣ Energy Axis (Stimulation Level)

Critical for sleep design.

Values:

• VERY_SOFT
• SOFT
• MODERATE
• STORY_DRIVEN

Most library should sit in:

VERY_SOFT or SOFT

Story-driven pieces used earlier in routine.

This later becomes:

Routine sequencing engine.

⸻

4️⃣ Routine Position Axis

Huge SaaS lever.

Where does this audio sit in a bedtime flow?

Values:

• START — settle down
• TRANSITION — attention anchor
• FALL_ASLEEP — loopable
• NIGHT_WAKE — re-entry

Canonical note:

Use this 4-state model across all systems.
If legacy data contains `WIND_DOWN`, map it to `TRANSITION`.

Example:

Creation → START
Joseph → TRANSITION
Psalms Rest → FALL_ASLEEP

This becomes automated routines later.

⸻

5️⃣ Audience Age Axis

Even if you don’t market by age yet — store it.

Values:

• TODDLER
• CHILD
• FAMILY
• ADULT

Later unlocks:

personalized recommendations.

⸻

6️⃣ Format Axis (Product Variation)

Future-proofing.

Values:

• STORY
• AMBIENT
• LOOP
• EXTENDED
• MUSIC_LAYER
• WHISPER
• SHORT

This is your upgrade path without new stories.

Same narrative → multiple SKUs.

Massive leverage.

⸻

7️⃣ Scripture Axis (Structural Identity)

Non-negotiable.

Fields:

• book
• story
• testament
• theme keyword

This enables:

search
SEO
bundles
curriculum
seasonal sets

⸻

Narrative: RESCUE

Scripture: genesis / noah / old_testament / protection

That is one audio fully mapped.
