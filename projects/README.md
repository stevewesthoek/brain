# Projects

Project-specific context for active, paused, and exploratory work.

## Purpose

Use project folders for:
- project overview and scope
- target audience and positioning
- implementation notes
- meeting notes and assets
- project-specific decisions and constraints

## Rule

Prefer project-local files when discussing a specific project, but prefer:
- `operations/decision-log.md` for architecture decisions
- mind repo (`02-strategy/organisations/`) for business/brand truth
- mind repo (`05-areas/personal-identity/`) for personal context

for global behavior, identity, and safety.

## Notes

- Not every folder is equally active.
- Some folders are exploratory or incomplete.
- If a project becomes important, give it its own README and a clear start-here file.
