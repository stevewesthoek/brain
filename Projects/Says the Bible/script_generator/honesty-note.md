# Intellectual honesty note (keep this separate)

There is no clinical manual saying,
“Design bedtime Scripture with 3 repetition waves.”

But there is overwhelming evidence that:
• Novelty activates cortex
• Predictability calms
• Repetition reduces cognitive load
• Slow speech lowers autonomic activation
• Emotional reassurance reduces anxiety
• 20–30 min matches sleep latency

This structure synthesizes those principles.
