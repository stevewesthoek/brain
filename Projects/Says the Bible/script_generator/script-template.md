# SCRIPT TEMPLATE v1.4 (Sleep-Optimized Structure)

## 0:00–2:30 — Parasympathetic Entry

Goal:
Lower arousal.

Mechanics:
• Slower rate from first sentence
• Breathing cues
• No doctrinal complexity
• Low novelty

Why:
Initiates vagal regulation.

---

## 2:30–20:00 — Narrative Core (Gradual Deceleration)

Structure per unit:
• 2–2.5 min narrative
• 30–45 sec reflection loop

Reflection Loop (fixed order):
1. Observation
2. Meaning
3. Personal Connection
4. Permission to Rest

Rules:
• Narrative intensity decreases across units
• Sentence length shortens gradually
• Descriptive novelty reduces over time

Why:
Cognitive load must taper, not spike.

---

## 20:00–25:00 — Integration Block (No New Story Content)

Absolutely no new events.

Content:
• Restate key truths
• Identity reinforcement
• Safety language
• Longer pauses

Why:
Sleep onset window often begins here.
New narrative here would reactivate cortex.

This section bridges narrative → rhythmic mode.

---

## 25:00–30:00 — Rhythmic Sleep Loop

Structure:
Wave 1 — Core summary phrases
Wave 2 — Same phrases, slower
Wave 3 — Same phrases, longest pauses

No new vocabulary.
No theological expansion.
Only reinforcement.

Why:
Predictive coding model:
Confirmed patterns reduce neural error signals.

Sleep onset research:
Repetitive low-variance auditory input promotes drift.

Comparable mechanism:
Why white noise works.
Why lullabies repeat.
Why prayer repetition calms.

---

## Final Ratio

0–20 min → gentle narrative with micro reflections  
20–25 min → reinforced meaning and safety  
25–30 min → looped rhythmic phrases with extended pauses  

Reflection proportion increases in final 10 minutes.

This is intentional.
