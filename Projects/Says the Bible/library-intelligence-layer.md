📄 LIBRARY INTELLIGENCE LAYER

Version: v0.1
Date: 2026-02-27
Purpose: Turn a static library into an adaptive routine system
Confidence: High (0.91)

⸻

Core Principle

The library is not a catalog.
It is a behavioral record.

Every interaction teaches the system:

What calms
What is skipped
What repeats
What signals sleep

Intelligence emerges from usage patterns, not explicit settings.

⸻

Three Intelligence Levels

This prevents overbuilding.

Level 1 — Structural Intelligence (Now)

Based on taxonomy only.

The system knows:

Story type
Emotional role
Routine position
Energy level
Loop eligibility

This already enables routing.

No user memory required.

⸻

Level 2 — Session Intelligence (Next)

The system observes sessions.

Signals:

What starts nights
Where playback stops
What repeats
Night wake triggers
Time-of-day patterns

This creates:

Soft recommendations
Routine suggestions
Next audio hints

Still deterministic.

⸻

Level 3 — Behavioral Intelligence (Later)

Now patterns exist.

The system can infer:

Child prefers Psalms to stories
Falls asleep faster after ambient
Needs safety content mid-night
Responds to repetition

Routing becomes adaptive.

This is the SaaS brain.

⸻

Core Data Signals (Minimal but Powerful)

Do not track everything.
Track meaningful transitions.

Key events:

Routine started
Audio completed
Audio stopped early
Loop engaged
Night wake playback
Re-download
Favorite added

That’s enough.

These signals map behavior without surveillance.

⸻

Derived Metrics (Soft Inference)

From raw signals you can infer:

Sleep anchor audio
Comfort audio
High friction audio
Routine stability score
Repetition preference

No sensors required.

This is the elegance of routine products.

⸻

Intelligence Outputs

The system should eventually surface:

Start with this tonight
You usually fall asleep after this
Try this softer version
Your most calming story
Night wake suggestion

Language must remain gentle, not analytical.

Parents don’t want dashboards.
They want reassurance.

⸻

Library Structure Evolution

Phase 1:
Flat library

Phase 2:
Library + favorites

Phase 3:
Library + routines

Phase 4:
Library + adaptive suggestions

The same assets gain perceived value without new content.

That is leverage.

⸻

Recommendation Logic (Deterministic v1)

No ML.

Rules:

If repeated 3× → surface
If skipped 2× → deprioritize
If used during night wake → mark safety
If looped often → promote fall-asleep

Simple thresholds feel intelligent.

⸻

Bundle Intelligence (Revenue Layer)

The system can detect:

User buys similar emotional tags
User builds routine manually
User uses library frequently

Then surface:

Relevant bundle
All-access hint
Playlist suggestions

This makes upsells feel helpful.

⸻

Child Profile Readiness

Even before profiles exist, design for them.

Store signals scoped by:

user_id
future profile_id

So migration later is trivial.

Do not couple intelligence to accounts too tightly.

Household > individual.

⸻

Device Intelligence (Later)

Different devices imply different contexts.

Smart speaker → night wake
Phone → parent control
Kids device → routine independence

Library intelligence should incorporate device context eventually.

Not required now, but schema should allow it.

⸻

Content Lifecycle Intelligence

The library should know:

New
Stable
High value
Routine core
Rarely used

This drives:

Homepage order
Bundle composition
Price justification
Translation priority

Your best assets surface automatically.

⸻

UX Pattern

The intelligent library should feel like:

A calm bookshelf that subtly rearranges itself.

Not a feed.
Not recommendations shouting.
Gentle hints.

Quiet intelligence builds trust.

⸻

Technical Guardrails

To enable this later:

Playback events must exist
Taxonomy must be consistent
Assets must have stable IDs
Purchases must map cleanly
Routines must be referenceable

You already built most prerequisites.

That’s unusual.

⸻

Failure Modes

Do not:

Expose raw analytics
Gamify sleep
Over-personalize early
Change routines aggressively
Create surprise

Routine products value stability over novelty.
