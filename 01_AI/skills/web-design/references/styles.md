# Web Design Style Catalog

Use this catalog to pick a style quickly. Each style includes: best fit, visual cues, and implementation notes.

1) Minimalism + Swiss
- Best fit: enterprise SaaS, dashboards, documentation, B2B sites
- Visual cues: strict grid, generous whitespace, tight type scale, neutral palette
- Notes: default for clarity; prioritize legibility and information hierarchy

2) Neumorphism ("Neumorphia")
- Best fit: wellness, meditation, simple control panels
- Visual cues: soft shadows, raised surfaces, low contrast
- Notes: use sparingly due to accessibility; avoid critical UI on low-contrast elements

3) Glassmorphism
- Best fit: modern SaaS, fintech, analytics
- Visual cues: frosted glass cards, blur, vibrant gradients behind
- Notes: keep contrast high; use subtle blur to avoid readability issues

4) Brutalism
- Best fit: portfolios, art, experimental brands
- Visual cues: raw HTML feel, bold type, hard edges, unpolished textures
- Notes: only when the brand wants deliberate friction

5) 3D + Hyperrealism
- Best fit: gaming, product showcases, premium launches
- Visual cues: depth, lighting, realistic materials
- Notes: prefer light 3D accents; avoid heavy perf cost on marketing pages

6) Vibrant + Block-Based
- Best fit: startups, agencies, youth brands
- Visual cues: bold color blocks, chunky UI, high energy
- Notes: keep typography simple to balance color intensity

7) OLED Dark Mode
- Best fit: developer tools, night-first apps
- Visual cues: near-black surfaces, neon accents, crisp borders
- Notes: avoid purple-on-black defaults; ensure contrast ratios

8) Accessible + Ethical
- Best fit: government, healthcare, education
- Visual cues: high contrast, large type, clear UI patterns
- Notes: prioritize WCAG; reduce motion; keyboard-first navigation

9) Claymorphism
- Best fit: education, kids apps, playful SaaS
- Visual cues: soft clay buttons, rounded shapes, subtle depth
- Notes: limit to accents; keep core UI simple

10) Aurora UI
- Best fit: modern SaaS, creative agencies
- Visual cues: soft gradients, glowing edges, fluid color fields
- Notes: use gradients as backgrounds, not as text fills

11) Retro-Futurism
- Best fit: gaming, entertainment, music
- Visual cues: neon, grids, synth textures, chrome highlights
- Notes: use nostalgia deliberately; avoid overloading with effects

12) Flat Design
- Best fit: MVPs, mobile-first SaaS
- Visual cues: solid colors, minimal shadows, clean shapes
- Notes: good baseline for speed; ensure clear hierarchy

13) Skeuomorphism
- Best fit: legacy apps, premium physical metaphors
- Visual cues: realistic textures, shadows, physical affordances
- Notes: avoid unless brand needs it; can feel dated

14) Liquid Glass
- Best fit: premium SaaS, high-end ecommerce
- Visual cues: glossy surfaces, liquid highlights, reflective gradients
- Notes: use in hero and accents; keep UI controls crisp

15) Motion-Driven
- Best fit: storytelling, product launches
- Visual cues: scroll-linked animation, staged reveals
- Notes: keep animations purposeful; provide reduced-motion fallback

16) Micro-Interactions
- Best fit: mobile apps, touch-first UI
- Visual cues: subtle hover/tap states, small feedback loops
- Notes: consistent timing; avoid noisy motion

17) Inclusive Design
- Best fit: public services, education, healthcare
- Visual cues: clear labels, accessible type, multilingual-ready layouts
- Notes: avoid icon-only controls; respect cognitive load
