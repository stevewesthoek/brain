# Brain Repository Identity Synchronization

## Current identity

Workbench is the current product identity for human-facing product, operational,
architecture, and contributor documentation.

## Historical identity

BuildFlow remains as a compatibility and historical identifier. Its presence in
technical configuration, migration evidence, archived material, and generated
artifacts does not indicate a pending product rename.

## Preserved identifiers

The following remain unchanged:

- `BUILDFLOW_ACTION_TOKEN`
- BuildFlow repository and filesystem paths, including `buildflow` path segments
- BuildFlow domains, including `buildflow.prochat.tools`
- app IDs, service IDs, and deployment identifiers
- command names, including `buildflow-orchestrator.sh`
- Docker image, container, and volume names
- environment-variable names and credential-storage paths
- migration manifests, historical reports, generated artifacts, and test-fixture namespaces

## Rename policy

Only human-facing current terminology is synchronized to Workbench. Technical
compatibility identifiers and historical records remain unchanged.

This is a documentation and knowledge-record synchronization only. It does not
migrate infrastructure, credentials, domains, repository paths, APIs, commands,
containers, deployments, or runtime behavior.
