# I-7.8: Brain Console Script Approval Actions

**Status:** Complete
**Date:** 2026-06-01
**Repo:** Mind

## Summary

Enabled the Brain Console Script Drafts tab to send explicit approval actions to Brain Core.

The UI calls Brain Core only:

```text
POST /api/video-orchestrator/scripts/{jobId}/approve
POST /api/video-orchestrator/scripts/{jobId}/request-changes
```

It does not use the AWS SDK, read S3 directly, trigger generation, publish content, create video, or mutate Brain Core outside the approval endpoints.

## Approval UX

- Approve opens a confirmation dialog before sending.
- Approve defaults `approvedBy` to `Steve`.
- Approve supports optional notes.
- Request changes requires notes and blocks empty submissions.
- Review stays read-only and only opens the script preview.
- Actions refresh the Script Drafts view after success.

## Safety Rules

- Says the Bible shows: `Theology review required before approval.`
- Approval status is shown as one of `pending`, `approved`, or `changes_requested`.
- Approve is disabled once a script is already approved.
- Actions are disabled when Brain Core reports the script as uploaded or published.
- Error messages are surfaced safely without stack traces.
- The UI remains usable after request failures.

## What Does Not Happen Automatically

- No generation is triggered from Brain Console.
- No publish action is triggered from Brain Console.
- No video is created from Brain Console.
- No direct S3 access is performed from Brain Console.
- No AWS SDK calls are added to the plugin.
