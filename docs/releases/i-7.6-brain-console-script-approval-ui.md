# I-7.6: Brain Console Script Approval UI

**Status:** Complete
**Date:** 2026-06-01
**Repo:** Mind

## Summary

Added a read-only Script Drafts tab to the Obsidian Brain Console Video Orchestrator UI.

The view consumes Brain Core only:

```text
GET /video-orchestrator/script
```

It does not use the AWS SDK, read S3 directly, trigger generation, publish content, or approve scripts.

## UI Behavior

The Script Drafts tab displays:

- `jobId`
- `channelId`
- topic title
- script status
- approval status
- word count
- script preview

Review controls are visible but disabled:

- Review - not wired yet
- Approve - not wired yet
- Request changes - not wired yet

## Channel Badges

- Says the Bible: `Theology review required`
- ProChat: `Standard approval required`
- Other/unknown channels: `Approval required`

## States

Empty state:

```text
No script drafts found.
```

Error state:

```text
Brain Core script endpoint unavailable.
```

## Validation

Added:

```text
scripts/validate-brain-console-script-approval-view.sh
```

The validator checks:

- Brain Console view exists.
- Brain Core script client method exists.
- No AWS SDK imports.
- No direct S3 reads.
- `node --check` passes for the plugin bundle.
- `npm run typecheck` / `npm run build` if a Mind `package.json` provides them.
