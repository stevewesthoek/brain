# I-8.1: Interactive Video Prompt Draft API

**Status:** Implementation Complete ✓  
**Date:** 2026-06-01  
**Phase:** I-8 (Interactive UI → Draft Jobs)

## Overview

I-8.1 adds an interactive workflow for Steve to create draft video jobs directly from Brain Console by typing a prompt. This is a read-write operation that creates job metadata WITHOUT generation or publishing.

**Key constraint:** Draft job creation is approval-free and non-destructive — Steve can create unlimited drafts, then explicitly approve before generation proceeds (Phase 2).

## Endpoint

```
POST /api/video-orchestrator/jobs/create-from-prompt
```

### Request

```json
{
  "channelId": "prochat",
  "prompt": "AI can write code but not businesses",
  "requestedBy": "Steve"
}
```

**Fields:**
- `channelId` (required, string): Target channel ID (must exist)
- `prompt` (required, string): Topic/hook for the video (10–500 chars)
- `requestedBy` (required, string): User who initiated the request

### Validation

1. **Channel validation:**
   - Channel folder must exist at `channels/<channelId>/`
   - `channel.json` and `content-profile.json` must be present
   - `allowPublicPublishing` must be false (security check)

2. **Prompt validation:**
   - Length: 10–500 characters
   - Required, non-empty string

3. **RequestedBy validation:**
   - Required, non-empty string

**Error responses:**
- `400 invalid_channel` — Channel not found or misconfigured
- `400 invalid_prompt` — Prompt outside length bounds
- `400 invalid_request` — Missing required fields
- `400 config_missing` — Channel config or content profile not readable
- `400 write_failed` — Disk I/O error

### Success Response

```json
{
  "ok": true,
  "jobId": "prochat-prompt-1717225752000-ai-can-write-code",
  "channelId": "prochat",
  "topicId": "prochat-prompt-1717225752000",
  "scriptStatus": "draft",
  "approvalStatus": "pending",
  "nextStep": "approve_script",
  "createdAt": "2026-06-01T17:22:32.000Z"
}
```

## Job Folder Structure

Created at: `projects/video-orchestrator/cloud/jobs/<jobId>/`

```
jobs/<jobId>/
├── metadata/
│   ├── topic.json          ← Topic/prompt context
│   ├── script.json         ← Script metadata (status: draft, approval: pending)
│   └── [NO publish.json]   ← Publishing config NOT created
├── scripts/
│   └── script.md           ← Initial script content (from prompt)
└── [NO assets/]            ← Video assets NOT created
```

## Implementation Details

### JobId Generation

Timestamp-based with slug:
```
<channelId>-prompt-<timestamp>-<slug>
```

Example: `prochat-prompt-1717225752000-ai-can-write-code`

- `<channelId>` = channel ID
- `<timestamp>` = unix milliseconds
- `<slug>` = first 30 chars of prompt (lowercased, alphanumeric+hyphens)

### Approval Status

All draft jobs created with:
- `approval.status = "pending"`
- `approval.required = true` (from channel content-profile)
- `approval.theologicalReviewRequired` = channel-specific value (false for ProChat)

### Script Status

All draft jobs created with:
- `scriptStatus = "draft"` (not "ready" or "generating")
- No video assets
- No publish.json created

### File Permissions

Creates job folder with standard permissions (readable, writable, traversable).

## Security Properties

✅ **No automatic generation** — Draft status is terminal until approval  
✅ **No publishing** — publish.json not created  
✅ **Channel validation** — Unknown channels rejected  
✅ **Public publishing blocked** — Rejects channels with `allowPublicPublishing: true`  
✅ **Approval required** — All drafts start with `approval.status = "pending"`  
✅ **Prompt length bounded** — 10–500 chars prevents abuse  
✅ **Timestamp-based uniqueness** — Job IDs globally unique by construction  

## Known Limitations (Phase 1)

- Draft script is placeholder only (just prompt text)
- No AI-powered script generation from prompt
- No direct Brain Console UI hook yet (use API + shell scripts)
- No image/title/hook generation
- Script wordCount remains 0 until actual generation

These are addressed in Phase 2 (I-8.2: Prompt → Script Generation).
