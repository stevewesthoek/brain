# I-7.7 Script Approval API

Date: 2026-06-01

## Summary

Brain Core now exposes safe local API endpoints for approving generated video scripts or requesting changes before any downstream video generation or publishing step.

## Endpoints

- `GET /api/video-orchestrator/scripts/{jobId}` keeps the existing compatible read behavior and returns script metadata from `projects/video-orchestrator/cloud/jobs/{jobId}/metadata/script.json`.
- `POST /api/video-orchestrator/scripts/{jobId}/approve` marks a script as approved.
- `POST /api/video-orchestrator/scripts/{jobId}/request-changes` marks a script as requiring changes.

## Safety Contract

- Job IDs are rejected unless they contain only letters, numbers, dots, underscores, and hyphens.
- Missing `script.json` returns a safe error.
- Approval writes only `metadata/script.json`.
- Approval does not create or change `publish.json`.
- Approval does not trigger video generation, upload, or publishing.
- Approval is rejected when publish/upload metadata already exists.
- `says-the-bible` responses include `theologyReviewRequired: true`.
- Explicit human approval is required for every script for now, even if a channel profile does not declare `guardrails.requiresHumanApproval: true`.

## Validation

Run Brain Core locally, then run:

```bash
cd projects/video-orchestrator/cloud
scripts/validate-script-approval-api.sh
```

The validation uses the fixed safe job `approval-api-test-001`, exercises request-changes and approve, verifies `approvedBy` and `approvedAt`, and confirms no generation artifacts or publish metadata are created.
