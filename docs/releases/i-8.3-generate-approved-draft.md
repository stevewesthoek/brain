# I-8.3: Generate Approved Draft Video Artifacts

**Status:** Implementation Complete ✓  
**Date:** 2026-06-01  
**Phase:** I-8 (Interactive UI → Draft → Generation)

## Overview

I-8.3 upgrades the existing `generateApprovedScript` function from validation-only to real generation triggering. When an approved draft is sent to the generation endpoint, it now:

1. Copies narration from S3 fixture
2. Triggers AWS Step Functions workflow for video assembly
3. Writes generation status and publish metadata locally
4. Returns execution ARN for tracking

**Key constraint:** No publishing to YouTube. Generation creates artifacts with `publishStatus: "pending"` and `publishBlocked: true`.

## Endpoint

```
POST /api/video-orchestrator/scripts/{jobId}/generate
```

### Request

```json
{
  "requestedBy": "Steve"
}
```

### Validation

1. **jobId format** — must be valid (alphanumeric, dots, underscores, hyphens; no `..`)
2. **Script metadata** — must exist at `metadata/script.json`
3. **Topic metadata** — must exist at `metadata/topic.json`
4. **Approval status** — must be `approved` (pending/changes_requested rejected)
5. **Theology review** — for Says the Bible channel, must have `theologicalReviewRequired: true` in approval
6. **AWS credentials** — `aws` CLI must be in PATH with valid credentials

### Success Response

```json
{
  "ok": true,
  "jobId": "prochat-console-gen-001",
  "generationStatus": "started",
  "generationStarted": true,
  "executionArn": "arn:aws:states:eu-north-1:909439522876:execution:prochat-video-skeleton-dev:console-gen-prochat-console-gen-001-1780338905222",
  "publishStatus": "pending",
  "publishBlocked": true
}
```

### Error Responses

| Code | Meaning |
|------|---------|
| `invalid_job_id` | jobId format invalid |
| `script_missing` | `metadata/script.json` not found |
| `topic_missing` | `metadata/topic.json` not found |
| `script_not_approved` | Approval status is not `"approved"` |
| `theology_review_required` | Says the Bible requires theology review but it wasn't completed |
| `dir_creation_failed` | Failed to create job directory structure |
| `status_write_failed` | Failed to write `metadata/status.json` |
| `narration_failed` | Failed to copy narration from S3 |
| `workflow_start_failed` | Failed to start Step Functions execution |
| `publish_write_failed` | Failed to write `publish.json` |

## Generation Workflow

### Step 1: Create directories
```
jobs/{jobId}/
  ├── metadata/    (already exists from draft)
  ├── audio/       (created)
  └── publishing/  (created)
```

### Step 2: Write status.json
Initial status: `status: "generating"`, `currentStep: "narration_started"`

### Step 3: Copy narration
Copies from S3 fixture at `jobs/test-001/audio/narration.mp3` to `jobs/{jobId}/audio/narration.mp3` in the same bucket.

### Step 4: Trigger Step Functions
- **State Machine:** `arn:aws:states:eu-north-1:909439522876:stateMachine:prochat-video-skeleton-dev`
- **Execution Name:** `console-gen-{jobId}-{timestamp}`
- **Input:** `{ jobId, videoKey: "jobs/{jobId}/video-generated/generated-001.mp4", audioKey: "jobs/{jobId}/audio/narration.mp3" }`
- **Execution ARN:** Captured and returned in response

### Step 5: Update status.json
After execution starts: `currentStep: "workflow_started"`, `executionArn: "..."`

### Step 6: Write publish.json
Both `metadata/publish.json` and `publishing/publish.json` contain:
```json
{
  "jobId": "prochat-console-gen-001",
  "publishStatus": "pending",
  "publishBlocked": true,
  "reason": "Generated from approved draft — awaiting explicit publish approval",
  "createdAt": "2026-06-01T18:34:35.882Z",
  "generatedBy": "interactive-prompt",
  "platforms": {
    "youtube": {
      "status": "pending"
    }
  }
}
```

**Key:** No `videoId` or `url` fields. No YouTube upload data.

## Implementation Details

### AWS Configuration (hardcoded in provider)

```typescript
const AWS_REGION = 'eu-north-1';
const S3_BUCKET = 'prochat-video-dev-909439522876-eu-north-1-an';
const STATE_MACHINE_ARN = 'arn:aws:states:eu-north-1:909439522876:stateMachine:prochat-video-skeleton-dev';
const NARRATION_FIXTURE_KEY = 'jobs/test-001/audio/narration.mp3';
```

### AWS CLI Invocation

Uses `execFile` from `node:child_process` to invoke AWS CLI commands:
- `aws s3 cp` — copy narration fixture from test job
- `aws stepfunctions start-execution` — trigger video assembly workflow

All commands:
- Use `--no-cli-pager` to suppress output paging
- Specify `--region eu-north-1` explicitly
- Use `--query` and `--output text` for clean parsing

### Type Updates

**`GenerationTriggerResponse`** expanded with:
- `generationStatus: 'complete' | 'started'`
- `finalVideoKey?: string`
- `thumbnailKey?: string`
- `publishStatus: 'pending'`

All existing code paths updated to return these fields.

## Security Properties

✅ **Only approved scripts generate** — pending/changes_requested rejected  
✅ **Approval bypass prevented** — validation happens before any AWS calls  
✅ **No automatic publishing** — `publishBlocked: true` prevents upload  
✅ **Execution tracking** — `executionArn` returned for monitoring workflow status  
✅ **Audit trail** — `generatedBy`, `createdAt`, `reason` in publish.json  
✅ **Theology review enforced** — Says the Bible scripts require review flag  
✅ **No secrets in response** — AWS credentials not exposed  

## Known Limitations

- **Narration is mocked** — copies from `test-001` fixture, not AI-generated
- **No image/title generation** — uses prompt as title directly
- **No thumbnail generation** — Step Functions workflow generates, not captured locally yet
- **No direct publish** — requires separate explicit publish workflow (I-8.5)
- **Async completion** — endpoint returns immediately with `executionArn`, workflow continues in background

These are addressed in Phase 3 (I-8.5: Publish to YouTube).
