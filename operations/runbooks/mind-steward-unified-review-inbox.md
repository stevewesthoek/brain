# Infinite Brain Unified Review Inbox

## Status

The unified review inbox is a deterministic projection over existing evidence producers. It does not create a database, memory system, authority layer, or decision store.

## Inputs

The projection can combine:

- Mind inbox ingestion and PDF extraction envelopes;
- conversation evidence candidates;
- maintenance intelligence findings;
- lifecycle analysis findings;
- operational feedback signals.

Each item retains a source reference, provenance, confidence, uncertainty, freshness, relevance, authority owner, Mind/Brain impact, and `requires_human_decision: true`.

## Output and activation

Use the existing Brain-local runtime boundary:

```text
runtime/local/mind-steward/unified-review/latest.json
runtime/local/mind-steward/unified-review/latest.md
```

The projection is generated by `tools/scripts/mind-steward-unified-review-inbox.mjs` when called by an approved local workflow. It never writes Mind or Brain canonical files and never calls providers.

Review states are:

```text
needs_review | accepted | rejected | deferred | archived
```

They are workflow states only. Decisions must use the existing human decision boundary and bounded transaction flow.

## Authority boundary

Mind owns meaning, importance, priorities, and strategic decisions. Brain owns evidence handling, workflow, validation, and operational intelligence. The unified projection never decides importance automatically.
