# Prompts

Index of reusable prompt libraries.

- `ai-prompts.md` — general prompt collection
- `ai-blogpost-template.md` — blog template
- `ai-spreadsheet-language-content.md` — spreadsheet/language/content prompts
- `ai-writing-creativity-academic.md` — writing and academic prompts
- `sintra-framework.md` — copy frameworks
- `webdesign.md` — web design prompt
- `jack-roberts/` — imported prompt pack normalized into markdown files

## Rule

Keep prompt libraries here.
If a file defines channel operations or agent behavior, put it under `ai/publishing/` or `ai/agents/` instead.
