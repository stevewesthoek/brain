4. **In Claude Code:** Use `/design-system` to automate this

---

## Getting DESIGN.md Files

All files are hosted at `https://getdesign.md/`. To use in your projects:

**Option 1 — Claude Code:**
```
/design-system
[select a design from this library]
→ I copy it to your project automatically
```

**Option 2 — Manual:**
```bash
curl https://getdesign.md/linear/design-md -o DESIGN.md
# Or copy from brain/ai/design-systems/library/LINEAR/DESIGN.md
```

**Option 3 — Reference Custom (prochat.tools):**
```bash
# prochat.tools has a custom DESIGN.md already in the project
cat ~/Repos/prochattools/web/prochat/DESIGN.md
```

## Add New Designs

Found a design you like? Add it to this library:

1. Download from `https://getdesign.md/<brand>/design-md`
2. Save to `brain/ai/design-systems/library/<BRAND>/DESIGN.md`
3. Add entry to this file
4. Commit and push

---

## Create Custom Designs

Built a great design system? Make it reusable:

1. Create `brain/ai/design-systems/custom/<project-name>/DESIGN.md`
2. Use 9-section format
3. Document: "Extracted from [project]"
4. Share with team

**Example:** prochat.tools DESIGN.md at `brain/ai/design-systems/custom/prochat-tools/DESIGN.md`
