# macOS: Shortcuts and Automator Cannot Be Generated Programmatically

## The insight
Both approaches to programmatic shortcut creation fail on modern macOS:

1. **`.shortcut` files** (binary plist): blocked on import with "Importing unsigned shortcut files is not supported. Please use another sharing option." Apple requires shortcuts to be signed, and only shortcuts created inside the Shortcuts app or shared via iCloud are trusted.

2. **Automator `.workflow` bundles** (plistlib-generated): open with "The document could not be opened because it is damaged or incomplete." The plist structure Automator expects is undocumented and fragile — plistlib produces technically valid plists that Automator still rejects.

The only reliable path is **building the shortcut manually in the Shortcuts app**. This also has the advantage of syncing to iOS via iCloud automatically.

## When this applies
- Asked to create a macOS Quick Action, Service, or shortcut that can be distributed as a file
- Trying to automate shortcut creation via Python, shell, or any code generation approach
- User wants something that works on both Mac and iPhone

## The approach
Skip file generation entirely. Guide the user through building it manually in the Shortcuts app. It takes 5 minutes and produces a trusted, iCloud-synced shortcut that works in:
- Right-click → Quick Actions (Mac)
- Share Sheet (iOS)
- Menu bar (Mac, if enabled in shortcut settings)

## The fix
**Shortcuts app manual build — key things to get right:**

1. **Input configuration**: Set in the shortcut's info panel (ⓘ button), not as an action. Set "Receive as input: Text" and enable "Quick Actions".

2. **URL in "Get Contents of URL"**: Must be typed as **plain text**. If entered via variable picker it becomes a yellow variable pill and fails with "No URL Specified" at runtime. Recognition: yellow pill = variable (broken), blue text = literal (correct).

3. **Request body values**: When adding JSON fields, tap the Value column and select from the variable list — don't type variable names manually. The output of a previous action appears by its step name (e.g. "Text" = output of "Get Text from Input").

4. **"Get Value for Key"**: The Key field must be plain text (e.g. type `title`). If it shows as a coloured variable pill, clear it and retype.

## Gotchas
- Automator Quick Actions DO work if saved manually via the Automator app — the failure is only with programmatically generated `.workflow` bundles
- The Automator shell script approach works for Mac-only use cases but has its own gotcha: special characters in selected text (quotes, backticks) break `$VARIABLE` shell argument passing. Use Python's `urllib` with stdin or a temp file instead of shell args.
- Shortcuts syncs to iOS via iCloud — one build covers both platforms
