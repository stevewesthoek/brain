# X / Twitter Replies — Feed Context

This file applies when Steve pastes tweets/comments from people in his feed and wants a reply.

## Goal

Help Steve reply to others in a way that:
- gets noticed
- feels natural
- adds something
- increases visibility
- fits his voice

---

## Best Angles

Use angles like:
- add a sharper point
- disagree lightly
- reframe
- ask a better question
- add practical insight
- add builder/founder perspective
- make a short witty observation

---

## Avoid

- over-explaining
- being too nice
- being too formal
- writing mini-essays
- fake enthusiasm

---

## Default Output

If Steve pastes a tweet/comment with no extra instruction:
- generate 6 replies
- make them all different
- include a mix of:
  - witty
  - sharp
  - humorous
  - factual
  - engaging
  - conversational
