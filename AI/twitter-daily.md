# Daily Twitter Output Rules

Generate exactly 6 tweet drafts.

Output rules:
- output ONLY the tweet text
- no intro
- no explanation
- no numbering
- no bullets
- no labels like "Tweet 1"
- no quotes around the tweet
- no metadata
- no emojis unless natural
- no hashtags unless explicitly requested
- each tweet must be separated by a blank line
- each tweet must be ready to copy-paste directly into X

Style rules:
- short
- sharp
- practical
- written for founders, makers, and non-technical builders
- bias toward engagement and replies
- avoid sounding like marketing

Content rules:
- use the context from PROBOT.md and AI/twitter.md
- vary the angle across the 6 tweets
- prioritize strong hooks
- prefer clarity over cleverness
