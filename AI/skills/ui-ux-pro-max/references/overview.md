# UI-UX Pro Max Overview

UI-UX Pro Max is a design intelligence skill that works as a searchable database for:
- UI styles
- Color palettes
- Font pairings
- Chart types
- UX guidelines
- Stack-specific best practices

Catalog counts (current data set):
- 67 UI styles
- 96 color palettes
- 56 font pairings
- 25 chart types
- 98 UX guidelines
- 13 tech stacks

Supported stacks include html-tailwind, react, nextjs, astro, vue, nuxtjs, nuxt-ui, svelte, swiftui, react-native, flutter, shadcn, and jetpack-compose.
